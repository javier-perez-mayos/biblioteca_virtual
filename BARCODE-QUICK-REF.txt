🔒 SSL STATUS
   ✅ HTTPS: Port 3443 (primary)
   ✅ HTTP→HTTPS redirect: Port 3300
   ✅ Certificates: ./ssl/ (self-signed, 365 days)
   ✅ Camera access: Enabled (requires HTTPS)

🚀 QUICK START
   1. Open: https://localhost:3443/scan-barcode.html
   2. Accept SSL warning (first time only)
   3. Click "Start Camera" or upload image
   4. Point at ISBN barcode
   5. Get instant results!

📋 SERVER CONTROL
   Start:   npm start
   Stop:    pkill -f "node.*server.js"
   Check:   curl -k https://localhost:3443/scan-barcode.html -I

💡 TIPS FOR BEST RESULTS
   ✅ Good lighting
   ✅ Hold 10-15cm from barcode
   ✅ Keep barcode flat/parallel
   ✅ Hold steady 1-2 seconds
   ✅ Use HTTPS (required for camera)

🔧 TROUBLESHOOTING
   SSL Warning?     → Click "Advanced" → "Proceed to localhost"
   Camera blocked?  → Grant permissions in browser
   No detection?    → Improve lighting, try closer/farther
