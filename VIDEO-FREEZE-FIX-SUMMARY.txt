╚══════════════════════════════════════════════════════════════╝

🐛 PROBLEM:
Video was freezing when starting the barcode scanner

🔍 CAUSE:
Scan loop started before video stream was fully initialized

✅ SOLUTION:
Added proper video initialization sequence:

1. Wait for video metadata to load
2. Wait for video to start playing  
3. Add 300ms stabilization delay
4. Then start scanning

🔧 TECHNICAL FIX:

Before (causing freeze):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
video.srcObject = stream;
await video.play();
scanLoop(); // ❌ TOO EARLY!

After (fixed):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
video.srcObject = stream;

// Wait for metadata
await new Promise((resolve) => {
    video.onloadedmetadata = () => resolve();
});

// Wait for play
await video.play();

// Stabilization delay
await new Promise(resolve => setTimeout(resolve, 300));

// Now start scanning ✅
scanLoop();
